# 60秒人生ゲーム

TikTok縦動画の画面録画用に作った、GitHub Pages向けのHTML/CSS/JavaScript作品です。
外部ライブラリ・外部画像・外部フォント・著作物素材は使用していません。

## 使い方
1. このフォルダの中身をGitHubリポジトリ直下へアップロード
2. Settings → Pages → Deploy from a branch → main / root を選択
3. 公開URLを縦画面で開く
4. STARTを押すと約60秒で自動再生
5. スマホ画面録画、またはPCブラウザを縦比率にして録画

## 構成
- `index.html` 本体
- `style.css` キャラクター、背景、演出をすべてCSSで描画
- `script.js` 60秒タイムライン制御

## タイムライン
- 0:00-0:04 プロローグ
- 0:04-0:15 ヒーロー
- 0:15-0:27 サッカー
- 0:27-0:42 脚本・ゲームシナリオ
- 0:42-0:53 妻
- 0:53-1:00 エピローグ

## 補足
ウルトラマンそのものではなく「赤と銀の巨大ヒーローに憧れた」というオリジナル表現にしています。TikTokキャンペーン応募時の権利面を考えた仕様です。
