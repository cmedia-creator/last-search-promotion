都市伝説検索怪異 / GitHub Pages用

ファイル:
- index.html
- style.css
- script.js

基本操作:
1. 検索欄に「都市伝説　まとめ」と入力して検索
2. 3番目のスニペットが「ここではありません。」になる
3. Rキーを押すたびに演出フェーズが進行
   - もう少し下です。
   - 7番目「それです。」
   - 「なぜ押さないのですか」
   - 「待っています。」
   - 「押してください。」
4. 後半で7番目タイトルをクリックするとLAST SEARCH画面へ移行

動画撮影時の推奨操作:
- 検索
- 3番目で停止
- R
- 下へスクロール
- R
- 7番目で停止
- 一度クリック（初回は遷移せず「なぜ押さないのですか」へ）
- 別検索を挟む場合は任意語を入力して検索
- 元画面へ戻してRで「待っています」「押してください」を表示
- 7番目を再クリック

補足:
- ブランド名「Search」5回クリックでもRキー同様にフェーズを1段階進められる
- PC/スマホ両対応
- 外部通信なし、静的HTML/CSS/JSのみ
- GitHub Pagesへそのままアップロード可能
