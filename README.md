# LAST SEARCH - 動画怪異デモ

GitHub Pagesにそのまま置ける、1クリックで怪異が連続再生されるデモです。

## ファイル
- `index.html`
- `style.css`
- `script.js`
- `cat.jpg`

## 演出
1. 猫画像
2. クリックから約0.55秒で画面クラッシュ
3. 不正アクセス検知
4. `CODE NAME OGOTAKA`
5. 大量ログ
6. `LAST SEARCHへアクセスします`
7. LAST SEARCHトップ画面

## GitHub Pages
この4ファイルをリポジトリ直下へアップロードして、
Settings → Pages → Deploy from a branch → main / root を選択してください。

録画し直すときは、最後のLAST SEARCH画面を素早く3回タップすると最初に戻ります。
