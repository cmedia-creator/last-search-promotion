LAST SEARCH 宣伝動画用デモ

流れ:
普通の検索エンジン風画面
→ 心霊スポット検索結果（全リンク同じ遷移先）
→ 心霊スポット一覧（恐怖度★1〜3）
→ 少しスクロールすると画面にヒビ
→ ブラックアウト
→ LAST SEARCH
→ 何か入力しようとすると「ラストサーチにようこそ」自動入力
→ その言葉で検索
→ 2000年代風掲示板
→ 404号資料室さん入室
→ 会話
→ 「見えていますか？」自動入力
→ 404号資料室さん退出
→ 再度「見えていますか？」自動入力
→ 右上の疑似ブラウザ×ボタン
→ 0〜100%ロード
→ 一致判定：13% / 結果：失敗
→ 通常検索画面へ戻る

GitHub Pages:
index.html / styles.css / app.js を同じ階層へアップロードしてください。

注意:
本物のブラウザ終了・戻る操作は妨害しません。
右上の×は演出用の疑似ブラウザ操作です。
一般的な日本のポータル検索エンジン風UIで、特定サービスのロゴや画面をコピーしていません。


修正版 v2
- 1回目の「見えていますか？」は自動入力後に投稿。
- 404号資料室退出後、2回目の「見えていますか？」は自動入力だけ行い、投稿はしない。
- 2回目の入力完了後、右上の疑似×ボタンが点滅。
- ×を押すと照合画面へ進み、「一致判定：13% / 結果：失敗」後に通常検索へ戻る。
